# One page for any doctor who prescribes

**For a child with mosaic variegated aneuploidy caused by changes in both copies of the *BUB1B* gene.**

This page exists so that a parent does not have to explain a rare syndrome in a ten-minute appointment. It is written to be handed over.

---

## Read this first, before anything else on the page

> ## This page is NEVER a reason to change cancer treatment.
>
> It does not apply to chemotherapy or radiotherapy given to treat, control or prevent the return of a cancer. **Do not reduce, delay, omit or swap any medicine in a cancer treatment plan because of anything written here.** Those decisions belong to the oncology team and the tumour board.
>
> It also does not apply to a medicine given urgently, where no equivalent exists: a water tablet, a steroid, an antibiotic, an anti-sickness medicine for an acute problem.
>
> **This page is only about routine, non-urgent prescribing for something unrelated to cancer.**

---

## Why this child is different

The gene affected here makes a protein that checks chromosomes are shared out correctly when a cell divides. In this child that check is weakened, so some cells end up with the wrong number of chromosomes.

A small number of ordinary medicines interfere with that same step. In a child whose cells are already struggling with it, there is a reason to prefer an alternative when a good one exists. **This has not been tested in a child with this syndrome.** It is a precaution based on how the medicines work, not on evidence of harm in this child.

## Medicines worth a second thought, and what can be used instead

Only for routine, non-urgent prescribing. **Ask the child's specialist team before changing anything.**

| Medicine | A possible alternative to discuss |
|---|---|
| Colchicine | An anti-inflammatory (NSAID) |
| Griseofulvin, for fungal infection | Terbinafine |
| Albendazole or mebendazole, for worms | Pyrantel, where it is licensed for the child's age and weight, with hygiene measures. **If no licensed alternative exists, treat the infection. This is a reason to ask, not a reason to leave worms untreated.** |
| Topiramate | Levetiracetam |
| Acetazolamide | Ask the team |
| A water tablet (loop diuretic), when not urgent | A thiazide |
| High-dose intermittent vitamin D | Daily vitamin D, with the blood level checked |
| Growth hormone, or mecasermin | Only through the endocrine team, never started outside it |

**Two of these, acetazolamide and topiramate, also make kidney stones more likely, which matters because of the kidney finding below.**

## Three questions worth asking the specialist team

**1. When was the calcium in the kidneys first seen on a scan? Was it on any scan before birth?**
The clinical summary says it was present at birth. The two usual explanations both happen after birth. Which one is right changes which kidney medicine is the correct one, and they point in opposite directions. One date from the records settles it.

**2. Can the *UGT1A1* result be read from the genetic testing already done, before any irinotecan is ever needed?**
The sequencing is already paid for and already done. This costs nothing to look up and is a safety check for one specific chemotherapy drug.

**3. Given that the change is in this particular gene, how close should the cancer surveillance be?**
Not all genes causing this syndrome carry the same cancer risk. The risk follows how badly the chromosome check fails. This gene is one of the two where it fails badly, and the research recommends close surveillance for exactly this group. Two other additions cost nothing: a blood count added to a blood test that is already happening, and a preference for ultrasound or non-X-ray scans where either would answer the question.

## What nobody knows

There is no medicine that treats this syndrome. Nothing on this page is expected to reduce this child's risk of cancer, and no test here can show whether it has. Every suggestion above is a precaution or a question, not a treatment.

The reasoning behind every line, with its sources and its uncertainties, is in `REPORT_track2.md` in the accompanying repository.
