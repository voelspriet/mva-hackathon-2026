# Archive: the working record

Everything here was produced on the way to the two reports and is kept because the reports cite it. None of it is a deliverable, and the simulated seats in `panel/`, `panel2/` and `referees/` are generated text, not evidence; `SIMULATED_PANELS.md` says what that cost this project.

| | |
|---|---|
| `panel/`, `panel2/` | Two simulated specialist panels, thirteen seats, briefed blind to each other. Transcripts as written |
| `creative/` | Ten divergent lenses written without access to the panels |
| `audit/` | Five partitions checking 577 claims against primary sources, the summary built from them by `build_summary.py`, the exclusion audit, the data-claim checks, and the five prompts the checking ran under |
| `verify/` | Three primary-source verification passes |
| `referees/` | Three simulated referee reports, written without access to the working files |
| `research_loop/` | The question loop that followed the referees |
| `synthesis/` | What each review layer caught, and the test of this project's own headline claim |
| `vertex/` | Cross-model runs: the redaction script, the outputs of two other model families, and the refusal experiment |
| `video_script.md`, `PROMPT*.md` | The pitch script and the prompts that produced the panels |
| `SIMULATED_PANELS.md` | Method note: simulated seats are not a source of evidence |
| `VERIFICATION_INDEX.md` | The map of the checking |

Citations in the reports of the form "creative D §6", "V3 §1d", "referee 2" or "round4_grand_moderator" resolve to the correspondingly named files in `creative/`, `verify/`, `referees/` and `panel/`.
